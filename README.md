Sprint_7 - Автотесты для API Яндекс.Самокат

В данном проекте реализованы автотесты для проверки API сервиса аренды самокатов "Яндекс.Самокат".

1. Основа: 
— Python 3.11
— Pytest — фреймворк для написания тестов
— Requests — библиотека для отправки HTTP-запросов
— Allure — для генерации красивых отчетов

2. Установка зависимостей: pip install -r requirements.txt

3. Запуск тестов: 
— Для запуска всех тестов с подробным выводом (verbose):pytest;
— Для генерации Allure-отчета: pytest --alluredir=allure-results, allure serve allure-results.

4. Структура проекта:
— api_client.py - модуль с функциями для отправки HTTP-запросов к API (обернуты в шаги Allure)
— data.py - модуль с тестовыми данными (фейклвые логины, пароли и т.д)
— conftest.py - фикстуры для подготовки и очистки тестовых данных
— helpers.py — вспомогательные функции (генерация данных курьера, формирование payload для заказа).
— urls.py` — константы с адресами (эндпоинтами) API.
— tests/ — папка с тестами:
    test_create_courier.py — тесты на создание курьера.
    test_login_courier.py — тесты на авторизацию курьера.
    test_create_order.py — тесты на создание заказа (с параметризацией цветов).
    test_get_orders_list.py — тест на получение списка заказов.
— requirements.txt - список зависимостей; 
— allure-report/- сгенерированный отчет о тестировании.

ПРИМЕЧАНИЯ: Здравствуйте! По поводу проверки тела ответа в тестах на негативные сценарии (где ожидается ошибка валидации): 
На тестовом стенде Яндекс.Самоката наблюдается нестабильность — при отправке запросов без обязательных полей сервер часто возвращает код 504 (Gateway Timeout) и текст "Service unavailable", либо принудительно разрывает соединение, вместо ожидаемого 400 Bad Request с JSON-телом.

Чтобы тесты не падали ложно (False Negative) из-за нестабильности стенда, в код добавлена защита: проверка тела ответа выполняется только при получении кода 400. Если сервер недоступен (504 или обрыв соединения), тест корректно пропускается (Skipped), так как проверить тело ответа у упавшего сервера невозможно. При этом сам код ответа строго проверяется в assert.
